🎯 C'est quoi le but?

Faire une fleur avec 4 pétales jaunes!

Les pétales jaunes doivent entourer le centre blanc ☀️

🧩 Comment faire ?

  1. Trouve une arête jaune n'importe où sur le cube.
  2. Amène l'arête jaune sur la face blanche.
  3. Répète pour les 4 arêtes jaunes.

Pour cette étape, aucun algorithme n'est requis. Utilise seulement tes intuitions et des rotations simples !

💡 Conseils utiles

  • Tourne le cube dans tes mains pour repérer les arêtes jaunes.
  • Si une arête jaune est « coincée » en bas, utilise R U R' pour la libérer.
  • Ne t'en fais pas pour les couleurs autour – ce sera important à l'étape suivante !
  • Astuce : Commence par trouver UNE arête jaune, puis concentre-toi sur celle-là avant de chercher les autres.
